Game

The Sealed Belfry

A 2D puzzle-platformer I designed and built on my own. A young witch goes down into a sealed abbey to ring its great bell, solving rooms by writing four-word rune sentences onto stone cubes: wind, fire, ice, light and portals. Most rooms have more than one solution, and there's a Daily Puzzle and an Endless mode of generated rooms.

  • Godot 4
  • GDScript
  • Procedural generation
  • Windows & Web
  • Solo project

Desktop app

EZ Host

A free Windows app for hosting Minecraft and Project Zomboid servers on your own PC, with no commands and no router settings. It installs Java and mod loaders for you, manages mods, backups and a live world map, and gives friends an online address through playit.gg. Open source, with an automated installer build.

  • Electron
  • Node.js
  • JavaScript
  • GitHub Actions
